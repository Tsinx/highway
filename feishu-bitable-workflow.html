工作流（Workflow）：构建你的专属AI Agent

从自动化到智能化，学习使用工作流设计复杂业务流程，并打造能自主判断和执行的AI Agent。

工作流 vs. 自动化：核心区别

工作流是自动化的超集，它继承了自动化的"触发-执行"模式，但提供了更强大的流程编排能力。可以理解为，自动化适合处理线性的、简单的任务，而工作流则专为复杂的、多分支的业务流程而生。

自动化(Automation)

  • 适用于简单、线性的流程。
  • 例如：当记录新增时，自动发送通知。
  • 不支持复杂的逻辑判断。
  • 配置界面更聚焦于单个步骤。

工作流(Workflow)

  • 支持条件判断 (if-else)，可创建分支流程。
  • 可视化画布界面，流程全貌一目了然。
  • 节点可拖拽、重命名，配置更灵活。
  • 适用于构建复杂的、多节点的Agent。

工作流的核心能力：条件判断

工作流最核心的升级就是引入了"条件判断"节点。你可以设置一个或多个条件，工作流会根据数据是否满足这些条件，自动执行不同的后续操作。这就像给自动化流程装上了一个"大脑"，让它能够根据不同情况做出不同选择。

实战案例：构建财务报销审批助手

接下来，我们将通过一个实战案例，展示如何结合多维表格、多模态AI和工作流，构建一个智能的财务报销审批助手。该助手能自动分析员工提交的报销申请及附件，判断其合规性，并根据结果自动推进或驳回流程。

完整操作演示

视频案例：构建一个从数据录入、AI分析到智能审批的全流程财务助手。

第一步：搭建财务报销数据表

首先，创建一个"财务报销审批"数据表，用于收集和管理所有报销申请。关键字段包括：

  • 报销事由 (文本)
  • 报销金额 (货币)
  • 发票/凭证 (附件，允许多个)
  • 提交人 (人员)
  • 审批状态 (单选：待审核、待审批、已驳回、已支付)
  • AI审核建议 (多行文本，用于存放AI的分析结果和建议)
  • 审批意见 (多行文本)

第二步：设计工作流与AI Agent

在多维表格中新建工作流，触发器设置为"当新记录创建时"。核心逻辑如下：

  • 节点1：AI多模态识别与分析
    • 操作：选择"AI生成文本"，并使用支持多模态能力的模型（如豆包1.6 Pro）。
    • 输入：引用记录中的"报销事由"、"报销金额"以及"发票/凭证"附件。
    • Prompt (指令)：
      你是一个严谨的财务审批助手。请根据以下报销信息和发票图片，判断是否符合公司规定（例如：金额是否超标、发票是否合规、事由是否合理）。 报销事由：{报销事由} 报销金额：{报销金额} 请严格按照以下JSON格式输出结论： { "is_compliant": true/false, "reason": "判断理由的简要说明", "suggestion": "给提交人的修改建议（如果不合规）" }
    • 输出：将生成的JSON结果填充到"AI审核建议"字段。
  • 节点2：条件判断分支

    基于"AI审核建议"字段的内容进行判断：

    • 条件：如果"AI审核建议"中包含 `"is_compliant": true`。
    • 如果满足条件 (合规)：
      • 更新记录：将"审批状态"修改为"待审批"。
      • 发送通知：向财务审批人发送飞书消息，提醒其有新的报销单需要审批。
    • 如果不满足条件(不合规)：
      • 更新记录：将"审批状态"修改为"已驳回"。
      • 发送通知给审批人：提醒有一条不合规的申请已自动驳回，并附上AI的判断理由。
      • 发送通知给提交人：发送飞书消息，告知其报销申请被驳回，并附上AI给出的具体"suggestion"（修改建议）。

通过工作流，我们成功构建了一个具备初步智能的AI Agent。它不再是简单的线性任务执行者，而是能够根据复杂规则进行判断、分发任务的智能助手，极大地提升了内容生产的效率和质量。
